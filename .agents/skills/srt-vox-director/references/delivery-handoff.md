# 新手平台交接

用户是新手，或问「从哪开始」「参考图哪里来」「传到哪」「在哪个平台用」时必读。

## 五件东西，先分清

| 东西 | 是什么 | 从哪来 | 去哪 |
|---|---|---|---|
| 参考图提示词 | 一段描述一张画面的文字 | 本 skill 输出 | 图片生成的提示词框 |
| **风格板** | 一张分六格的样板图，全片共用一张 | skill 包里**已经有的现成文件** | 图片生成的**图片输入位**，每镜都传 |
| 参考图 | 一张 PNG/JPG，画的是这一镜的**目标构图** | 图片生成器的输出 | 图生视频的图片输入位 |
| 视频提示词 | 一段带时间码的运动描述 | 本 skill 输出 | 图生视频的提示词框 |
| 视频片段 | 一个 MP4 | 视频生成器的输出 | 剪辑软件的时间线 |

**风格板和参考图是两张完全不同的图，新手最容易混**：

```
风格板   全片只有一张，skill 包里现成的，你不用生成
         传给图片平台，告诉它「这个风格长什么样」
参考图   一镜一张，是图片平台生成出来的结果
         传给视频平台，当垫图（模型据此重生成第 0 帧并演化）
```

风格板在 `assets/style-board/` 里，文件名就是所选风格的编号加名字。
它长得像一张材料样板——六个格子分别是色板、字体、材质、组件、场景、厚度线索。
**这是给图片模型看的，不是给你挑风格用的**（挑风格看 `style-samples/`）。

**必须讲清楚两件事**：

1. 参考图是用参考图提示词生成出来的，不是 skill 包里预置的文件。
   用户问「参考图在哪」时，先解释它由提示词生成，不要只指 `assets/` 目录。
2. 参考图画的是这一镜的**目标构图**（想呈现的核心画面），上传后模型把它当**垫图**、
   重新生成第 0 帧并演化到终态。所以生成片的第 0 帧与上传图常常**并不一致**——
   这是正常的预期行为，不是出图失败，也不需要重生成。

## 按能力讲平台，不要先讲产品名

1. **规划平台** —— 运行本 skill，产出分镜、台账、参考图提示词、视频提示词。
2. **图片生成平台** —— 把参考图提示词变成 PNG/JPG。
3. **图生视频平台** —— 接收 PNG/JPG 加视频提示词，返回 MP4。
4. **剪辑平台** —— 合成旁白、片段、字幕、音乐并导出。

一个产品可能覆盖多项能力。同一产品同时具备图片生成和图生视频时，用户不必换平台。

用户不想自己选时，给默认路线：

```text
ChatGPT Images —— https://chatgpt.com/
→ Google Flow —— https://labs.google/fx/tools/flow
→ 剪映 —— https://www.capcut.cn/?lang=zh
```

必须声明：账号资格、地区、配额、价格、可用模型、可选时长、按钮名称都可能变化，
以生成时的实时界面为准。

## 逐步操作清单

目录结构见 [delivery-contract.md](delivery-contract.md) 第 8 节。
下面路径里的 `S01` 是**镜号**，不是风格 ID。

**所有相对路径的基准都是输出目录，也就是你那个 `.srt` 文件所在的目录。**
分镜表是该目录下的 `storyboard.md`，提示词在 `01_提示词/` 里，一镜一个文件。

```text
00 打开 01_提示词/S01.md，本镜的参考图提示词和视频提示词都在里面
01 复制里面的参考图提示词
02 粘贴到图片生成的提示词框，画幅按分镜表填（默认 16:9）
02b 把风格板传到图片生成的图片输入位（路径在提示词文件开头写着）。
    全片每一镜传的都是同一张，不用换。平台不接受额外图片输入就跳过这步，
    并把提示词里「随附的风格板」那三行删掉
03 生成多张，挑一张通过「参考图八项」的（清单在 delivery-contract.md 第 8 节，
   目标构图与「无运动模糊 / 形状完整」这三项最容易漏）
03a 若出图里出现了格子、标签条、并排的方形样本，那是风格板的版式漏进来了：
    确认「随附的风格板」那三行还在，再重出
04 下载，命名为 02_参考图/S01_reference.png
05 打开图生视频模式，不要用文生视频模式
06 把 S01_reference.png 传到首帧 / 图片输入位
07 粘贴镜 01 的视频提示词
08 时长选择分镜表（`storyboard.md`）里的「生成时长」，不是「自然时长」
09 生成并下载，命名为 03_生成视频/S01_clip.mp4
10 检查生成片的开场状态是否符合视频提示词的描述（第 0 帧不必和上传图一模一样，
   上传图是垫图，模型会重新生成——只要开场各部件的位置和动作起点对得上就行）
11 在剪辑软件里按 SRT 时间码对齐；片子比旁白长就裁掉尾部，短就把最后一帧定格补上
12 后期叠加完整字幕、密集数据表、多位小数、必须逐字准确的品牌文字
```

**拆分镜多两步**（分镜表 `标记` 列以 `拆分：` 开头的那些镜）：

```text
09a 先按上面流程生成片段 a，得到 03_生成视频/S05a_clip.mp4
09b 把 S05a_clip.mp4 拖到播放器或剪辑软件，定位到最后一帧，导出单帧
    存为 02_参考图/S05b_bridge.png
09c 用这张图当片段 b 的首帧，回到第 06 步，
    粘贴 01_提示词/S05b.md 里的视频提示词
```

这样接缝处两帧完全相同，硬切也看不出来——比另外出一张图去凑一致可靠得多。

每镜重复。不要把参考图提示词粘进视频提示词框，除非产品明确要求合并提示词。

## 两条关键提醒

**时长要选生成时长。**
分镜表里有「自然时长」和「生成时长」两列。生成时选**生成时长**（4/6/8/10 秒之一），
因为平台只能生成这几个长度。它取的是离旁白最近的一档，所以可能比旁白长一点点，
也可能短一点点，差值那一列会写明是哪种。

**差值在剪辑里处理，两种方向。**
生成 6 秒、旁白 5.2 秒（余量 0.8）→ 把尾部 0.8 秒裁掉，或留一小段与下一镜重叠做转场。
生成 4 秒、旁白 4.9 秒（补差 0.9）→ 把最后一帧定格，拉长 0.9 秒补上，几帧而已看不出来。
两种情况都不要在旁白之间插停顿去凑长度，那会让音画越来越对不上。

## 两种路线

**单平台**（当前产品同时具备图片生成和图生视频时）

```text
skill 输出 → 图片生成 → 下载或直接复用 → 图生视频 → 下载片段 → 剪辑
```

**多平台**

```text
规划平台 → 复制参考图提示词 → 图片平台 → 下载 PNG/JPG
→ 视频平台 → 上传 PNG/JPG 并粘贴视频提示词 → 下载 MP4
→ 剪辑平台
```

## 新手交付块

新手模式的完整包末尾附上这一段口语化的操作卡。它与 [delivery-contract.md](delivery-contract.md)
第 9 节的「小白下一步卡」是同一张卡的两个版本：那一份是结构化的交付模板（带平台能力、
界面位置等列），这一份是面向新手的简化口语版，步骤一一对应、措辞更短。两份改动时要同步。

```text
下一步怎么做
（所有路径都相对于你那个 .srt 文件所在的目录）

0. 打开：01_提示词/S01.md
1. 复制：里面的参考图提示词
2. 打开：图片生成入口
3. 粘贴到：图片提示词输入框
3a. 上传：风格板（路径在提示词文件开头）。全片每镜都传同一张，不用换
3b. 验收：对照「参考图八项」，不过就重出这一张
3c. 出图里冒出格子、标签条、并排方块 = 风格板版式漏进来了，重出
4. 下载文件名：02_参考图/S01_reference.png
5. 打开：图生视频入口（不是文生视频）
6. 上传到：首帧 / 图片输入位置
7. 粘贴：视频提示词 S01
8. 时长选择：分镜表里的生成时长
9. 下载文件名：03_生成视频/S01_clip.mp4
9b. 检查：生成片的开场状态符合视频提示词的描述（第 0 帧不必和上传图一致）
10. 导入剪辑时间线，按 SRT 时间码对齐
11. 按差值处理尾部：余量裁掉，补差用末帧定格补上
12. 后期添加：完整字幕、密集数据表、多位小数、重要品牌文字

拆分镜（分镜表 `标记` 列以 `拆分：` 开头的）多两步：
生成完片段 a 之后，从成片截末帧存为 02_参考图/S05b_bridge.png，
用它当片段 b 的首帧，再走一遍 5–9。
```

用户指明了平台时，把能力名换成该平台实际可见的字段名，但只在已确认的情况下替换。

## 常见卡点

| 用户说 | 怎么答 |
|---|---|
| 参考图在哪 | 先解释它由参考图提示词生成，再说下载后存成什么名 |
| 风格板在哪 | 在 skill 包的 `assets/style-board/` 里，是现成文件，不用生成。文件名＝所选风格的编号加名字 |
| 风格板和参考图有什么区别 | 风格板全片一张、现成的、传给**图片**平台；参考图一镜一张、生成出来的、传给**视频**平台 |
| 出图里冒出一堆格子和标签 | 风格板的版式漏进画面了。检查提示词里「随附的风格板」那三行还在不在，补回去重出 |
| 参考图看着像成品/像终态 | 正常。参考图画的是这一镜的目标构图（想呈现的核心画面），不一定是动作起点 |
| 生成片的第 0 帧跟我传的图不一样 | **这是正常的**。上传图是垫图，模型会重新生成第 0 帧并演化到终态，不必逐像素一致。只要开场状态和视频提示词描述的起手对得上就行 |
| 传上去没反应 | 检查是不是用了文生视频模式，应改用图生视频模式（让平台接收上传图当垫图） |
| 画面和图对不上 | 检查图片与视频的画幅是否一致，不一致要重生成或先裁剪 |
| 字生成错了 | 用该镜的空白载体版本重出，精确文字放后期叠加；完整修法见 [troubleshooting.md](troubleshooting.md) 第 5 节 |
| 视频比配音长 | 正常，那是余量，剪辑时裁掉尾部 |
| 视频比配音短 | 也正常，那是补差，把最后一帧定格拉长补上 |
| 只有光在动 | 走 [troubleshooting.md](troubleshooting.md) 第 1 节的修复 |
| 能不能帮我生成 | 说明本 skill 只交付文本提示词，不生成任何图片或视频 |
