# 题材蓝图

需要题材专属的分镜策略时读。

与同类工具的区别：**旁白已由 SRT 给定**，所以这里不规定怎么写内容，
只规定「拿到这类内容的 SRT，应该怎么切镜、配什么风格、走什么视觉序列」。

## 怎么用

```
1. 通读 SRT，匹配下面的题材类型
2. 取该类型的推荐风格进入 style-selector 打分
3. 用该类型的视觉序列指导切镜时的候选切点
4. 落实该类型的分镜注意事项与风险提示
```

题材不在表内时，按信息形状就近取用（机制类看科普，时序类看历史，对比类看产品）。

## 科普与机制

| 项 | 内容 |
|---|---|
| 视觉序列 | 真实现象 → 观察窗 → 剖面 → 内部结构 → 因果箭头与一个物理过程 → 回到现实与结论 |
| 推荐风格 | S09 科学切片、S15 皮影机械（因果链）、S02 黏土定格（轻科普） |
| 切镜要点 | 一个因果步骤一镜。出现「因为…所以…」时那里是强候选切点 |
| 风险 | 不得编造解剖或微观结构；专业结构与数字标 `待核实` |

箭头不要超过三条，多因果步骤必须分镜。

## 历史与人物

| 项 | 内容 |
|---|---|
| 视觉序列 | 一张照片或一件实物 → 地图展开 → 时间线 → 关键文件 → 红线因果 → 今日画面与结论 |
| 推荐风格 | S10 历史档案、S13 木刻版画、S08 水墨长卷 |
| 切镜要点 | 年份、地名、人名出现处是天然切点 |
| 风险 | 姓名、日期、地图、引文、肖像权必须核实 |

## 数据与商业

| 项 | 内容 |
|---|---|
| 视觉序列 | 变化问题 → 折线变道路 → 柱状变楼体 → 业务变街区 → 风险变断路 → 城市全景做结论 |
| 推荐风格 | S05 数据城市、S07 极简几何、S19 博物模型（体量与系统感） |
| 切镜要点 | 每个指标一镜，不要把三个数字塞进一镜 |
| 风险 | 短数字可直接上屏；密集图表与多位小数走 `post only` |

## 产品与流程

| 项 | 内容 |
|---|---|
| 视觉序列 | 用户问题化为卡住的装置 → 产品从蓝图组装 → 功能沿轴分离 → 输入处理输出 → 一个真实场景 → 重新合体 |
| 推荐风格 | S11 产品蓝图、S01 现代纸艺 |
| 切镜要点 | 「第一步/第二步」「首先/然后」是强候选切点 |
| 风险 | 不得虚构功能、接口、界面、集成、指标 |

## 教程与方法

| 项 | 内容 |
|---|---|
| 视觉序列 | 当前困惑 → 方法卡逐张亮出 → 每张配一个实例 → 前后对比 → 成果打开 → 学习路径成路 |
| 推荐风格 | S18 马克笔记、S01 现代纸艺（方法卡逐张亮出） |
| 切镜要点 | 步骤编号即镜号，一步一镜，不合并 |
| 风险 | 不得夸大效果或承诺结果 |

## 校园招新与社团招募

| 项 | 内容 |
|---|---|
| 视觉序列 | 一句直击的提问 → 现状痛点 → 我们提供什么 → 三件具体的事 → 成员成长或作品 → 报名路径 |
| 推荐风格 | S17 深蓝撕纸、S01 现代纸艺、S03 毛毡手工 |
| 切镜要点 | 连续的设问句（「想…吗」「想…吗」）各自成镜，节奏靠短镜堆叠 |
| 风险 | 不得虚构社团规模、获奖、师资、就业结果 |

设问句往往只有两三秒，多半落进 `短镜`（自然时长 < 3.0 秒；恰好 3.0 秒的按正常镜算）。
尾部按 storyboard-algorithm 第 6 节的尾部契约表选档，不要强行与相邻镜合并。
这类题材的差值率天然偏高，触发提示时按 storyboard-algorithm 第 6 节的选项 a 接受即可，
不必回头改切点。

## 文化与非遗

| 项 | 内容 |
|---|---|
| 视觉序列 | 器物特写 → 工序拆解 → 匠人动作 → 材料来源 → 今日应用 → 传承结论 |
| 推荐风格 | S08 水墨长卷、S13 木刻版画、S04 矿彩壁画、S20 复古波普（复古艺术向） |
| 切镜要点 | 每道工序一镜 |
| 风险 | 不得复制宗教图像、伪造铭文印章、误用民族符号 |

## 观念与心理

| 项 | 内容 |
|---|---|
| 视觉序列 | 一个反直觉的现象 → 常见误解 → 真实机制 → 一个具体情境 → 边界与例外 → 可执行的建议 |
| 推荐风格 | S16 错位拼贴、S21 美漫风格（冲击框做反直觉钩子）、S12 漫画证据、S06 字体装置 |
| 切镜要点 | 转折词（其实、然而、但是）是强候选切点 |
| 风险 | 不得给医疗、法律、金融的个性化建议；相关表述标 `待核实` |

## 公益与科普提醒

| 项 | 内容 |
|---|---|
| 视觉序列 | 路线图 → 三张步骤卡 → 错误与正确对照 → 联系与行动清单 |
| 推荐风格 | S14 剪纸剧场、S18 马克笔记（步骤卡与圈注） |
| 切镜要点 | 对照类内容用同一构图的两镜，靠转场锚点连起来 |
| 风险 | 医疗、法律、金融、安全内容发布前必须核实；动画只做解释，不替代专业意见 |

## 系列化账号

同一账号做多期时，锁死：

- 固定的开场物件
- 三个固定颜色
- 标题卡固定位置
- 反复出现的转场锚点

只替换题目卡、案例卡、结论卡。风格 ID 写进 `state.json`，跨期沿用。
