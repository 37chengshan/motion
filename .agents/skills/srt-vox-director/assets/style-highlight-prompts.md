# 分界特写生成提示词（21 种风格）

> **正常流程不要读这个文件。** 它只在需要出或重出 `style-highlight/` 里的特写时才用得上。
> 选风格看 `references/style-gallery.md`，取风格块看 `references/style-library.md`。

用来生成 `assets/style-highlight/` 里的 21 张分界特写。

## 这批图干什么

三套图像资产各有读者，互不替代：

| 资产 | 读者 | 回答哪个问题 |
|---|---|---|
| `style-samples/` | 用户 | 这条风格拍出来整体什么样（同题材同构图，21 张横向直比） |
| `style-highlight/` | 用户 | **它和最像它的那条，差在哪** |
| `style-board/` | 图像模型 | 材质、配色、组件、厚度分别是什么（出图时当参考图上传） |

## 为什么是「分界」

`style-library.md` 每条风格的最后一栏是**禁止漂移**：点名最容易混的邻居，
并写死守住哪几件事就不会混。这一栏是全库信息密度最高的部分，
但它只以文字存在——用户选风格时看不到。

全景样图在这件事上最无力：S13 木刻版画和 S14 剪纸剧场缩成一张全景都是「红黑纸感」；
S20 复古波普和 S21 美漫风格共用 #E5A93C 与 #2B697A 两个色值，全景里几乎一样。
选错风格的代价是整条片子返工，而分界恰恰要凑近了才看得见：
S14 是层与层之间有**物理缝隙**，S13 是印在同一张纸上**压出凹陷**——
这个区别在全景图里只有几个像素。

所以这 21 张的构图规则只有一条：**把禁止漂移那一栏点名的分界特征，怼到主导整个画面。**

## 和风格板「厚度线索」格的区别

两者都是近距离、都在讲这条风格的物理机制，**必须写清区别，否则这批图就是第三套重复资产**：

| | 风格板的厚度线索格 | 分界特写 |
|---|---|---|
| 读者 | 图像模型 | 用户 |
| 内容 | 一个机制，孤立展示 | 这条风格做出来的**一处真实构造** |
| 取景 | 样板格里的一小块 | 满幅 16:9，构造本身占主导 |
| 判据 | 模型能不能学会这个机制 | 两个人并排看，能不能一眼分开两条风格 |

所以分界特写**不是材质样本的放大版**。它要拍的是「这条风格做的一件东西」，
让人看得出这是个真实存在的构造，只不过镜头凑得很近、分界特征占了大部分画面。

## 统一变量

这批图不做同题材控制变量——分界特征本来就每条不同，强行统一题材等于把要看的东西藏起来。
这里控制的是取景纪律：

| 项 | 值 |
|---|---|
| 画幅 | 16:9，1920×1080，与另外两套一致，便于并排看 |
| 内容 | **一处**构造，占满画幅，边缘自然切出画外 |
| 文字 | **零**。一个字、一个数字都没有 |
| 分格 | 不得拆成并排的两格三格，不得做成样本网格 |
| 情节 | 不表演任何故事，不出现可辨认的人物角色 |
| 焦点色 | 只落在一处 |
| 光照 | 按该风格自己的光照逻辑，不用通用棚拍打光 |

**零文字是刻意的。** 特写不需要标签，风格名在文件名与 `style-gallery.md` 的表里。
少掉汉字渲染，这批图重出一次的成本几乎为零，出错率也降到零。

## 与 style-library.md 的一致性

每条里的**风格块正文**（材质与解释世界那一段）与 `references/style-library.md` 的对应条目
逐字一致；每条的「绝不能出现」几行取自该风格的**禁止漂移**栏。改那两处时这里要跟着改。
`scripts/check_docs.py` 扫不到跨文件的风格块副本，只能靠人——
`assets/sample-prompts.md` 与 `assets/style-board-prompts.md` 有同样的约束。

## 固定框架段

**21 条都从下面这段开始，一字不改。**

```text
生成一张 16:9（1920×1080）的近距离特写，用于展示一种视觉风格的识别特征。

画面里只有一处构造，占满整个画幅，边缘自然切出画外。
它要看得出是这个风格做出来的一件真实东西，不是一块孤立的材质样本；
镜头凑得很近，下面指定的识别特征占据画面大部分面积。
景深浅，焦点精确落在识别特征上，其余部分自然虚化。

不得把画面拆成并排的两格、三格或样本网格——只有一处构造，一个焦点。
不表演任何情节，不出现可辨认的人物角色、故事动作或对峙场面。
需要人的位置一律用这个风格的无脸剪影占位，且不得成为画面主角。

整张图不出现任何文字、数字、标识、水印、印章、乱码或装饰性字符——一个字都没有。
不出现界面元素，不出现比例尺或标注线。

焦点色只落在一处，其余部分由这个风格的结构色与底色承担。

光照按下面的风格定义来，不使用通用棚拍打光。
```

## 出图后怎么验收

| 项 | 看什么 |
|---|---|
| 文字 | 一个字都没有。冒出任何字符即重出 |
| 满幅 | 构造占满画幅、切出画外。看得见完整物件轮廓、四周留一圈空，就是拍远了 |
| 单格 | 没有被拆成并排小格或样本网格 |
| 识别特征 | 「分界特征」那一行写的东西，是画面里第一眼看到的东西 |
| 绝不能出现 | 那几行禁止的元素，一件都没出现 |
| 焦点色 | 只在一处。铺开到两三处就失去指向了 |
| 情节 | 没有故事、没有角色、没有对峙 |
| **并排** | **与它的混淆邻居并排放，两张一眼分得开。分不开就是这批图失败了** |
| 光照 | 用的是这条风格自己的光，不是通用柔光 |

最后一项「并排」是这批图唯一真正的成败标准——
S13 和 S14 摆一起看不出区别，那这 21 张就白出了。

存成 `assets/style-highlight/SNN-风格名.jpg`，文件名与下面每节标题一致，一风格一张。

## S01 现代纸艺

存为 `S01-现代纸艺.jpg`

```text
[粘贴固定框架段]

风格与材质：
原创当代编辑感解释画面，材料是暖象牙色纤维纸、深炭灰卡纸、珊瑚红点缀、低饱和群青、
鼠尾草绿。用撕口纤维、旧杂志网点、丝网印颗粒、硬卡纸厚度；每个部件下有
10–20 像素偏移落影，贴面处再加 2–4 像素接触阴影，部件像浮在纸墙前方一两厘米。

主体：一台纸机械的局部——一段纸轨道正推着一张深炭灰硬卡纸卡片，贴在暖象牙纸墙上，
只入画轨道与卡片相接的那一段。
分界特征：两层阴影同时可见——卡片下方 10–20 像素的偏移落影，
外加贴面处 2–4 像素的接触阴影；硬卡纸的切口露出纸芯白边；
卡片像浮在纸墙前方一两厘米，不是印在上面。纸轨道的机械结构要看得出来。
焦点色：珊瑚红只落在轨道上的一处，不得铺开。

绝不能出现：这条风格最容易被认成 S17 深蓝撕纸与 S20 复古波普。
所以画面里不得有深藏蓝板面、带齿孔的黑色胶片条、美纹胶带，
也不得有圆角贴纸与粗的偏移描边。底必须是暖象牙纤维纸。

避免：统一的 UI 药丸、塑料 3D、随意的复古杂物。
```

## S02 黏土定格

存为 `S02-黏土定格.jpg`

```text
[粘贴固定框架段]

风格与材质：
精致的手工黏土定格摄影。主体由少数几块辨识度高的黏土部件拼成，
表面留有细微指纹与不规则的手作边缘。米白背景、柔和棚拍投影、克制的饱和度、温暖俏皮的配色。

主体：一只黏土捏成的小容器，只入画它的口沿与一块贴合上去的黏土部件的接缝。
分界特征：手指压出的指纹压痕，深浅有明显变化；手捏出的钝角厚边；
柔和棚拍投影的过渡要软，不留硬边。厚度靠黏土的体量与钝边读出来。
焦点色：赤陶珊瑚色只落在其中一块黏土上。

绝不能出现：这条风格最容易被认成 S03 毛毡手工。
所以画面里不得有可见纤维、缝线、布料织纹、绒毛边。
也不要用偏移落影——那是纸的语言。

避免：液体形变、玩具塑料。
```

## S03 毛毡手工

存为 `S03-毛毡手工.jpg`

```text
[粘贴固定框架段]

风格与材质：
手工毛毡与线的解释世界：可见纤维、缝线包边、布料层叠纵深、柔和暖光，
配色克制在米白、炭灰、珊瑚、蓝、鼠尾草绿之内。
信息由形状完整的毡片承载，不要做成毛糊糊的团块。

主体：一只毡片缝合成的布袋，只入画侧面那道缝线接边，其中一片一角翘离表面。

翘起那一角的轮廓是软塌的、不是硬折的。毛毡不反光，厚度靠轮廓的软塌读出来。
焦点色：珊瑚只落在其中一片毡上。

绝不能出现：这条风格最容易被认成 S02 黏土定格。
所以画面里不得有指纹压痕、捏出来的钝角硬边、任何看起来能被压扁重塑的块体，
也不要打出明显的落影。

避免：无定形绒球、低对比。
```

## S04 矿彩壁画

存为 `S04-矿彩壁画.jpg`

```text
[粘贴固定框架段]

风格与材质：
原创矿物颜料编辑感壁画，用砂岩米、青金蓝、孔雀石绿和克制的朱砂。
保留充裕留白、风化的颜料质感和当代的信息清晰度。不得复现某一幅具体的洞窟壁画。

矿物颜料是涂在墙上、靠残片边界分层的，两者的分层机制正好相反。

避免：复制宗教图像、伪造铭文、密集装饰边框。
```

## S06 字体装置

存为 `S06-字体装置.jpg`

```text
[粘贴固定框架段]

风格与材质：
实体的动态文字装置，由厚印刷字块、导轨、弹簧、滚轮、配重组成。
让文字通过物理排布本身去解释压缩、对比、因果或转化关系。辅助图形保持极少。
配色：暖米白、炭灰、生钢灰，以及信号红。

主体：一块厚印刷字块卡在导轨上的转角。**镜头压在字块的侧立面上**，
字块正面几乎不入画或严重出血——这样「它是印刷字块」靠厚度与导轨读出来，
画面里不需要出现任何字形。旁边入画一截弹簧与一块配重。
分界特征：字块可见的侧立面厚度；导轨、弹簧、配重的金属体量；
装置在暖米白墙面上投下的清晰硬影。机械部件必须至少两件入画。
焦点色：信号红只落在这一块字块上。

绝不能出现：这条风格最容易被认成 S07 极简几何。
所以不得做成纯平面的几何色块吸附，也不得把字块画成贴在墙上的平面。
没有机械部件就分不开这两条。

避免：任何可辨认的字形、随机英文。
```

## S07 极简几何

存为 `S07-极简几何.jpg`

```text
[粘贴固定框架段]

风格与材质：
瑞士风影响下的极简几何，但做成实体纸装置。象牙底、炭灰基线、群青轨道、

也不得有测量引线、尺寸标注、工程网格。投影一重就滑走了，阴影必须极轻或没有。

避免：装饰性肌理、渐变、任何小标签。
```

存为 `S09-科学切片.jpg`

```text
[粘贴固定框架段]

风格与材质：
精确的自然科学教学剖面，用科学教科书插版的视觉语言。

```

## S10 历史档案

存为 `S10-历史档案.jpg`

```text
[粘贴固定框架段]

风格与材质：
俯拍的旧木质档案桌：泛黄文件、折叠地图、黑白照片、报纸、信件、票据、邮票、
棉线和黄铜图钉。深褐、黑、米白、暗红。折痕、磨损、银盐颗粒、报纸油墨都要真实。

主体：俯拍一叠泛黄文件的边角，一枚黄铜图钉压住最上面一角，
一段暗红棉线从下面穿过，只入画这个角。
分界特征：纸张成叠时边缘的错位与卷角；折痕两侧的高低差；
顶光在每件实物边缘投下的短硬影；纸的泛黄与磨损。桌面是实的，东西是**摞**上去的。
```
