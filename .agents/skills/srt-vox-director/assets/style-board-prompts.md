# 风格板生成提示词（21 种风格）

> **正常流程不要读这个文件。** 它只在需要出或重出 `style-board/` 里的风格板时才用得上。
> 选风格看 `references/style-gallery.md`，取风格块看 `references/style-library.md`。

用来生成 `assets/style-board/` 里的 21 张风格板。

## 风格板是干什么的

**它是上传给图像平台的风格参考图，不是给人看的说明图。**
出每一镜的参考图时，把本风格的风格板连同该镜的参考图提示词一起传上去，
让模型有一份可看的材质与配色依据，而不是只靠文字描述去猜「暖象牙纸」是什么手感。

它和另外两套资产分工不同，三套都不可互相替代：

| 资产 | 谁看 | 干什么 |
|---|---|---|
| `style-samples/` | 用户 | 同题材同构图，21 张横向直比，用来**选风格** |
| `style-highlight/` | 用户 | 单风格的标志元素特写，用户对某风格感兴趣时看**细节** |
| `style-board/` | 图像模型 | 材质与配色的样板，出图时**当参考图上传** |

## 上传时必须附的一句话

风格板是分区陈列的样板，它的六格版式本身很强势。直接传上去而不做限定，
模型会把分区、标签条、样本方块一起画进镜头里。**每次上传都要在该镜的参考图提示词末尾追加：**

```text
随附的风格板只作材质与配色的依据：参考它的材质、配色角色、载体语言与厚度线索，
不复制它的分区版式、标签文字、样本方块与陈列方式。
本次要画的是一个完整场景，不是样板。
```

这条追加句的正典在 `references/prompt-templates.md` 第 4 节的参考图模板里，逐镜提示词原样取用，本文件不再重复其措辞。

## 统一变量

21 条共用同一套版面与同一组文字，**唯一变量是风格本身**，这样 21 张板可以横向直比：

| 项 | 值 |
|---|---|
| 画幅 | 16:9，1920×1080 |
| 六个分区 | 色板 · 字体 · 材质 · 组件 · 场景 · 厚度线索 |
| 字样两组 | `核心结论`（标题级）· `47%`（数字级） |
| 上屏文字 | 恰好九处：风格名 1 ＋ 分区标签 6 ＋ 字样 2 |
| 组件分区 | 上排带字载体留空不印字，下排无字装饰物件 |

**载体为什么留空。** 载体要展示的是「这个风格用什么形状承载文字」，形状本身就说明问题；
让它们印上字等于凭空多出三到五处汉字渲染，而字样分区已经把该风格的文字处理方式演示过了。
少一处上屏文字，就少一处漂字风险——这与 `prompt-keywords.md` 的渲染路线判断是同一个道理。

**组件为什么分两排。** 带字载体与无字装饰物件在这个 skill 里是两类东西：
载体进关键词台账、计知识点；装饰物件不进台账、不计知识点，数量按公式算出来。
两者的物件清单在 `style-library.md` 里也是分开写的。板上分两排，
模型才不会把装饰物件当成载体去填字，也不会把载体当成可以随手多撒几个的点缀。
下排不标数量——装饰物件的上限管的是**每一镜**放几个，不是样板上陈列几种。

## 为什么是这六格

底子是 `vox-style-ai-video-prompts` 那张风格板的六格：色板 / 字体 / 纸张纹理 / 组件 / 场景 / 动效。
这里只动两处——`纸张纹理` 泛化成 `材质`（21 种风格不全是纸），`动效` 换成 `厚度线索`。

挑选标准只有一条：**这一栏的信息，图像模型只靠文字描述学不会。**

| 收了 | 因为 |
|---|---|
| 色板 | 焦点色／结构色／底色的角色分工，靠文字说不清哪个是哪个 |
| 字体 | 该风格的文字处理方式，两组字样一眼看出标题级与数字级的层级差 |
| 材质 | 「暖象牙纤维纸」「半透明皮质」是手感，不是词 |
| 组件 | 该风格的物件词汇：什么形状承载文字、什么小物件属于这个世界 |
| 场景 | 材质**拼起来**是什么世界。六块材质样本只说明单块材料长什么样，说明不了它们如何组装 |
| 厚度线索 | 出图最常翻车的一项，且每条风格的厚度机制完全不同（落影／压印凹陷／重叠变深／亮度衰减） |

**场景为什么不能省，也不能拿 `style-samples/` 顶替。** 它演示的是三层纵深**用这个风格的真材质**
摆出来的样子——背景层、中景层、切在前景的近物，各自由哪种材料承担。
这和一张抽象的分层示意图不是同一件事，后者模型学不到材质与空间的对应关系。
`style-samples/` 是给人看的受控测试场景（同题材同四件物件），职责是横向比选风格，
不是给模型看的材质组装演示，两者不可互换。

场景格的**构图泄漏风险**由上面「上传时必须附的一句话」那条追加句负责挡住——
`vox-style-ai-video-prompts` 那张板同样带场景格、同样当参考图用，
靠的也是「不复制风格板的具体版式」这一句。

没收的两格：

**动效**——这条链路上到不了：板子只在**出图**这一步上传，视频模型拿到的是生成好的首帧
加文字提示词，从头到尾看不见这张板。四格前后对比图对图像模型收益为零，
而画面里多出的箭头与缩略图反而可能被当成元素画进镜头。
运动的正典在 `prompt-motion.md`，它服务的是视频提示词。
**什么情况下应该加**：如果这批板子除了当参考图，还要兼作人肉选风格的信息板，
那时动效格就有它的读者了——但那是另一个用途，得另出一版。

**人物／地图／数字／图表的统一处理**——`prompt-templates.md` 第 2 节的视觉圣经模板里有这一项，
但 `style-library.md` 的 21 条风格块**没有逐条定义**它。板上凭空画出来等于现造一份正典。
要收这一格，得先把这一项补进 21 条风格块，那是另一件事。

## 与 style-library.md 的一致性

每条里的**风格块正文**（材质与解释世界那一段）与 `references/style-library.md` 的对应条目
逐字一致，改风格时两处要一起改。

风格块另外两栏没有原样照抄，而是拆进了对应的分区，内容不变：
`配色角色` 拆进「色板」那几行（哪块是焦点色、哪几块承担结构、哪块是底），
`三层纵深` 拆进「场景」那几行（前景／中景／背景各放什么）。
拆是因为板上这两格要的是可画的陈列指令，不是规范文本；但**用词不得改**，
改了就等于在这里另立了一份风格定义。

`scripts/check_docs.py` 扫不到跨文件的风格块副本，只能靠人——`assets/sample-prompts.md` 有同样的约束。

## 固定版面段

**21 条都从下面这段开始，一字不改。** 每条各自的内容接在它后面。

```text
生成一张 16:9（1920×1080）的视觉风格板，用作图生视频项目的风格参考图。
这不是场景图，是一张分区陈列的材料样板：六个分区横平竖直排开，分区之间留出清晰间隔，
每个分区左上角有一条短标签。整张板本身也用这个风格自己的材质做成——
底、标签条、分隔线都是这个风格的材料，不是白色网页卡片，不是应用界面。

版面：
· 顶部通栏标题条，占高约 12%，准确显示风格中文名。
  标题条本身用这个风格的底色或结构色，**绝不用焦点色**——通栏色块是全画面最大的一片，
  用焦点色去做，等于把「焦点色只标当前主体」这条规矩当场推翻。分区标签同理。
· 左列约占宽 26%，上下两格：
  「色板」——四到六块方形色样排开，焦点色那一块尺寸明显更大，并单独错开一点位置。
  「字体」——两组字样，「核心结论」是标题级，「47%」是数字级，两者的层级差一眼可见。
  两组字样用这个风格的**主文字色**（多数风格是炭灰或黑，见各条的配色角色）。
  焦点色在这一格只落在一处很小的强调上，推荐做法是：
  「核心结论」四个字与「47」这两位数字全部保持主文字色，
  只把百分号染成焦点色，并在数字下方压一道焦点色短线。
  整句上焦点色、整串数字上焦点色，都算超。

**焦点色在整张板上只允许出现在三处**：色板里那一块、字体格的那一处强调、
以及场景中景的主体。
场景的主体若由多个同类部件组成（几块模块、几层纸、几个字块、几张卡），
**焦点色只落在其中一个部件上**，其余保持结构色——
各条风格的配色角色写的都是「当前正在讲的那**一个**」，是单数；
整组全刷成焦点色，等于把它摊平，它就不再指向任何东西了。
除此之外一律不用——包括标题条、分区标签、分隔线、边框，
以及**材质格的六块样本、组件格的载体与装饰、厚度线索格的特写主体**。
后面这三格最容易破例：它们本来就在展示这个风格的材料，
顺手把焦点色刷上去看着"更像这个风格"，但那样一来焦点色就不再指向任何东西了。
· 中列约占宽 44%，是整张板的视觉中心，上下两格：
  「场景」——占中列约三分之二高，是这一格里唯一一处成立的画面：
  用这个风格的真材质组装出一小片世界，前景、中景、背景三层必须一眼读得出来，
  每一层由哪种材料承担要看得清楚。画面里不出现任何文字。
  这一格只演示材质如何分层组装成空间，**不表演任何情节**：
  不出现可辨认的人物角色、戏剧动作、对峙或叙事瞬间；
  需要人的位置一律用这个风格的无脸剪影占位。
  「材质」——六块材质样本，等距排成两行三列，每块只展示材质本身，不带任何图形和文字。
  **每一块都必须是一片材料的表面或断面，不是一件物件。**
  箭头、球、螺栓、扣子这类成形的东西属于组件格，放进材质格就变成第二个组件格了；
  六块之间也要看得出区别，不要有两三块几乎同色同质。
· 右列约占宽 30%，上下两格：
  「组件」——分上下两排。上排是三到五件这个风格原生的文字载体，形状、材质、尺寸
  各不相同，全部留空，表面不印任何文字；下排是三到五种这个风格的无字装饰物件，
  体量明显小于上排。两排之间留出间隔，一眼能看出是两类东西。
  「厚度线索」——**一处**放大的宏观特写，只展示这个风格靠什么读出厚度。
  这一格不得再拆成两小格或三小格并列——拆开就变成第二个材质格了，
  它要的是把一个机制放到最大，不是多给几个样本。

只渲染以下九处文字，逐字准确，全部用这个风格自己的文字处理方式：
风格中文名一处；六个分区标签「色板」「字体」「材质」「组件」「场景」「厚度线索」；
字体分区里的「核心结论」与「47%」。
除此之外画面不得出现任何文字、数字、标识、水印、印章、乱码或装饰性字符。
组件格上排的载体一律留空，不得自己长出字来；场景格里也不得出现任何文字。

通用避免：光滑塑料 3D、玻璃与发光 UI 面板、霓虹、镜头光晕、渐变高光、
可识别的品牌标识、在世具名艺术家的个人风格、水印。
```

## 出图后怎么验收

| 项 | 看什么 |
|---|---|
| 文字 | 恰好九处，逐字正确，且各在自己那一格里——「核心结论」与「47%」都必须在字体格内，掉到别处就是版面错（S06 另有一处例外，见该条）。组件与场景两格没有自己长出字 |
| 焦点色克制 | 焦点色只出现在色板那一块与场景的主体上。被拿去做通栏标题条、大面积底色就算失败 |
| 场景内容 | 演示的是材质分层组装，不是一个故事。出现情节、角色、戏剧动作即重出 |
| 版面 | 六个分区都在，分区之间有清晰间隔，没有并成一大格 |
| 焦点色 | 色板里焦点色那块明显更大、位置错开，不是五块一样大 |
| 组件上排 | 三到五件载体形状明显不同，没有做成一排相似的矩形 |
| 组件下排 | 装饰物件全部无字、体量明显小于上排，两排分得开 |
| 场景 | 三层读得出来，且每层看得出是用哪种材质做的。退化成一行横排就算失败 |
| 厚度 | 特写展示的是这个风格自己的厚度机制，不是通用落影 |
| 材质 | 六块材质样本干净、不带图形和文字，能看出材料本身 |
| 底 | 整张板是用这个风格的材质做的，不是白底加彩色方块 |

存成 `assets/style-board/SNN-风格名.jpg`，文件名与下面每节标题一致。

## S01 现代纸艺

存为 `S01-现代纸艺.jpg`

```text
[粘贴固定版面段]

风格中文名：现代纸艺

风格与材质：
原创当代编辑感解释画面，材料是暖象牙色纤维纸、深炭灰卡纸、珊瑚红点缀、低饱和群青、
鼠尾草绿。用撕口纤维、旧杂志网点、丝网印颗粒、硬卡纸厚度；每个部件下有
10–20 像素偏移落影，贴面处再加 2–4 像素接触阴影，部件像浮在纸墙前方一两厘米。
把概念做成纸机械、纸轨道、纸卡片、胶片条、地图、标签和微缩模型。
层级要强，但不能像幻灯片或网页界面。

色板五块：暖象牙纸（底）、深炭灰卡纸、低饱和群青、鼠尾草绿、珊瑚红。
珊瑚红是焦点色，这一块最大并错开；炭灰卡纸与低饱和群青承担结构；
暖象牙纸是底；鼠尾草绿只用于环境。

材质六块：撕口纤维、旧杂志网点、丝网印颗粒、硬卡纸切口露出的纸芯白边、
10–20 像素偏移落影的样本、2–4 像素接触阴影的样本。

组件上排——载体三件，形状材质尺寸各不相同，全部留空：
一条撕边大标题纸块（粘贴类，尺寸最大）；
一段美纹胶带标签（粘贴类，窄长压平）；
一块印刷机牌立在折纸底座上（立牌类，直立带底座）。

组件下排——无字装饰物件四到六种，全部不带字：别针、回形针、纸轨道零件、
旧杂志网点碎片、空白印刷机牌、美纹胶带小段。

场景（用这个风格的真材质组装出一小片世界，三层必须读得出来，
画面里不出现任何文字）：
前景放撕纸边缘与胶带碎片，外加一张切到框边的近景卡片；
中景放一件纸机械；背景是一面素净的象牙纸墙，带极淡的网点面板。

厚度线索特写：一个部件的边缘放大——下方 10–20 像素偏移落影，
贴面处再叠 2–4 像素接触阴影，两层都要有；硬卡纸切口露出纸芯白边；
物件像浮在象牙纸墙前一两厘米，不是印在上面。

避免：统一的 UI 药丸、塑料 3D、随意的复古杂物。
不要滑向深蓝板底加胶片条，也不要滑向圆角贴纸加粗描边。
```

## S02 黏土定格

存为 `S02-黏土定格.jpg`

```text
[粘贴固定版面段]

风格中文名：黏土定格

风格与材质：
精致的手工黏土定格摄影。主体由少数几块辨识度高的黏土部件拼成，
表面留有细微指纹与不规则的手作边缘。米白背景、柔和棚拍投影、克制的饱和度、温暖俏皮的配色。
部件的按压、回弹、贴合都要像真黏土。

色板四块：米白（底）、鼠尾草绿黏土、灰蓝黏土、赤陶珊瑚色黏土。
赤陶珊瑚色是焦点色，这一块最大并错开；鼠尾草绿与灰蓝承担结构；米白是底。

材质六块：细微指纹压痕、手捏出的钝角厚边、不规则的手作边缘、
擀压过的平面、柔和棚拍投影的软过渡样本、压痕深浅变化的样本。

组件上排——载体三件，形状材质尺寸各不相同，全部留空：
一块压印黏土板（嵌入类，字位是压下去的凹槽）；
一枚悬挂黏土牌（悬挂类，顶端有穿孔）；
一枚盖章黏土代币（粘贴类，圆而薄，压在表面上）。

组件下排——无字装饰物件四种，全部不带字：散落的黏土碎屑、擀剩的边条、
指纹小球、压模空坯。

场景（用这个风格的真材质组装出一小片世界，三层必须读得出来，
画面里不出现任何文字）：
前景放几粒散落的黏土碎屑与一块略微失焦的近景黏土板；
中景放一件由三到四块辨识度高的黏土部件拼成的日常物件——一只杯子、一段剖开的果实
或一个带盖的小容器，部件之间的贴合处清楚可见；
```
