# AI 分享视频格式（Mac 桌面风格）

> 组件：`src/components/formats/MacDesktopFormat.tsx`

## 布局结构

```
┌─────────────────────────────┐
│  ☰ macOS 菜单栏（模糊玻璃）    │
│                             │
│  ┌───────────────────────┐  │
│  │ 🚥 屏幕录制窗口          │  │
│  │ （流动渐变边框 + 红绿灯）  │  │
│  │                       │  │
│  │                       │  │
│  └───────────────────────┘  │
│                    ┌─────┐  │
│                    │ 🤖  │← 虚拟数字人（呼吸动画）
│                    └─────┘  │
│      🧠 📊 🎯 💡 ⚙️ 📁      │← Dock 栏
└─────────────────────────────┘
```

## 核心元素

1. **菜单栏**：半透明毛玻璃 + 电池/WiFi 图标
2. **屏幕录制窗口**：
   - conic-gradient 流动渐变边框（角度随帧旋转）
   - 红绿灯按钮（关闭/最小化/全屏）
   - 弹簧缩放入场
3. **虚拟数字人**：右下角圆形头像，呼吸缩放动画 + 名字标签
4. **Dock 栏**：底部图标排，毛玻璃背景

## 用途

- 类型 D（真人操作录屏）的后期包装
- 类型 C（自有项目宣传）的流程演示
- AI 工具分享类内容

## 使用示例

```tsx
<MacDesktopFormat
  title="Remotion 项目演示"
  screenImage={staticFile("recording-frame.png")}
  avatar="🤖"
  presenter="AI 助手"
/>
```

## 素材建议

- 屏幕录制导出 PNG 序列或关键帧截图，作为 `screenImage`
- 数字人可替换为 Live2D / Rive 动画（@remotion/rive）
- 深色背景渐变 `#1a1d2e → #0d0f18`
