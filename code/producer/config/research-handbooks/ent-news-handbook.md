# 娱乐新闻方向研究手册

方向定位：**娱乐新闻**（国内外影视/音乐/明星动态）。每天单场。

> 本手册是 agent 的检索细节依据，由 SKILL.md 指向。修改需 bump version 并记录盲测。

## 一、信源表（三层）

### 官方/权威媒体层（免代理）

| 信源 | 端点 | 覆盖面向 |
|---|---|---|
| Variety | `https://variety.com/feed/` | 国际影视娱乐 |
| The Hollywood Reporter | `https://www.hollywoodreporter.com/feed/` | 国际影视娱乐 |
| 豆瓣电影 | `https://movie.douban.com/` （新片榜） | 国内影视口碑 |
| 时光网 / 1905 | 待验证 | 国内影视资讯 |

### 结构化数据层（TMDB，需免费 key）

| 用途 | 端点 | 说明 |
|---|---|---|
| 影片/剧集元数据 | `https://api.themoviedb.org/3/search/movie` | 海报、简介、评分、卡司 |
| 趋势 | `https://api.themoviedb.org/3/trending/movie/week` | 本周热门 |

- **TMDB 免费、无付费档**，额度 40 req/10s（个人使用充足）
- 需配 `TMDB_API_KEY`（themoviedb.org 注册 → Settings → API → 选 Developer）
- **缺失时**：TMDB 不可用走降级路径（不取海报/评分，仅用文字信息），不阻断流程
- 使用要求：需署名 TMDB

| 端点 | 说明 |
|---|---|
| `https://60s.viki.moe/v2/maoyan` | **猫眼实时票房**（电影热度硬指标） |
| `https://60s.viki.moe/v2/douyin` | 抖音热搜（娱乐舆情主阵地） |
| `https://60s.viki.moe/v2/rednote` | 小红书热点 |
| `https://60s.viki.moe/v2/weibo` | 微博热搜（明星动态） |
| `https://60s.viki.moe/v2/bili` | B站热门（二创/口碑） |

## 二、检索式与过滤器

### 收录标准（官方回应硬门槛）

**核心规则：无官方回应的传闻不收录。**
这是娱乐方向区别于其他方向的关键——娱乐谣言高发，必须有：
- 艺人/片方/平台**官方账号**回应，或
- 权威媒体（Variety/THR/官媒）确认报道，或
- 可验证的公开数据（票房/榜单/播出信息）

三者至少满足其一，否则**一票否决**。

### 收录白名单

- 影视作品：定档、开机、杀青、上映、票房、评分、获奖
- 音乐：专辑/单曲发布、演唱会、音乐节、榜单
- 艺人动态：官宣（恋情/婚育/解约/签约）、获奖、公开活动
- 平台动态：剧集/综艺排播、平台政策

### 关键词族

```
定档、官宣、开机、杀青、首映、票房、破亿、收官
获奖、提名、入围、影帝、影后、最佳
专辑、单曲、演唱会、巡演、音乐节
解约、签约、代言、合作
```

### 排除标准

- **无官方回应的传闻/爆料**（硬门槛）
- 狗仔偷拍、私生活未经证实细节
- 恶意引战、粉丝互撕
- 纯营销通稿无实质信息

## 三、降级链

| 层 | 主方案 | 降级 1 | 降级 2 | 终点 |
|---|---|---|---|---|
| TMDB 元数据 | TMDB(有 key) | 豆瓣 | — | **无海报/评分，纯文字**（不阻断） |
| 票房 | 60s `/v2/maoyan` | 豆瓣新片榜 | — | 空 + 标注 |
| 热榜 | 抖音/微博 | 小红书/B站 | DailyHotApi(6688) | 空热榜 + 标注 |
| 国际娱乐 | Variety/THR | — | — | 空 + 标注 |

**硬规则**：降级链终点必须是「空 + 标注」；TMDB 缺失**不阻断**流程，仅降级为无海报/评分。

## 四、打分权重

沿用 `score-and-rank.ts` 的 ai-pulse 模型：

```
total = heat * 0.4 + timeliness * 0.3 + sourceQuality * 0.3
```

方向特有加成：
- **官方确认加成**：官方回应/官宣 > 权威媒体报道 > 热榜传闻
- **数据卡加成**：有票房数字、评分、榜单名次 → 视频化价值高，加分
- **可视化加成**：TMDB 能取到海报/剧照 → 素材可得性加分（无素材降级为卡片页）
- **一票否决**：无官方回应且无权威媒体确认的传闻

去重：bigram Jaccard 相似度 > 0.8 判重。

## 六、内容安全红线（娱乐方向关键）

- **官方回应硬门槛**：无官方回应的传闻一律不收录（防谣言/防侵权）
- 不渲染艺人私生活，不传播未经证实的负面爆料
- 涉及劣迹艺人、法律纠纷，以官方通报/司法文书为准
- 引文 ≤40 字 + 标注 credit + 附 disclaimer
- 使用 TMDB 素材需署名；影视截图仅作评论引用，控制篇幅
- 国内外娱乐均覆盖，但国内部分遵循国内内容规范
