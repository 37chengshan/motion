# 06 · 发布（Windows，social-auto-upload）

> 发布在 **Windows 本地**完成，不需要 Mac publisher（publisher/ 标记废弃）。平台：B站 / 抖音 / 小红书 / 快手 / 视频号 + 微博。

## 发布工具

- CLI：`sau`（`code/producer/tools/social-auto-upload/sau_cli.py`；`uv pip install -e .` 后直接可用）。
- 账号 Cookie：`code/producer/tools/social-auto-upload/cookies/{platform}_{account}.json`（扫码登录一次后缓存）。
- 平台登录/账号：`data/accounts.json`（勿提交）。

## 流程

```bash
# 在 code/producer 下
npm run publish -- --platform bilibili [--account creator] [--draft-mode]   # 默认草稿闸口
# 或直接 sau：
sau bilibili up out/delivery.mp4 --title "..." --desc "..." --tags ...
```

## 发布前置条件（硬门）

1. **审查完成**：`review/` 有 completed 报告且 verdict ∈ {pass, warning}（warning 无 high issue）**或** 用户已确认的人工审查记录（agy 兜底路径，doc/05）。
2. **响度统一**：delivery.mp4 走 loudnorm + sfx 可听复检（doc/00 声音纪律）。
3. **文本/视觉审计**：简介、标题、标签、封面与视频内容一致；版权素材来源行齐（自有录屏/截图/免署名源）。
4. 封面与章节：成片附 `chapters.md`（HH:MM:SS 章节，间隔 ≥5s），B站编辑时粘贴。

## 平台要点

- **B站**：标题 + 分区 + 章节时间点 + 简介（附素材来源行 + 三连引导）。
- **抖音/小红书**：竖屏优先（1080×1920）；简介短；常驻件避右缘（点赞栏）。
- **微博**：`sau weibo login`（扫码）+ up。
- 发布后记录：`runs/<date>/<project>/publish.md`（平台/账号/链接/时间）。

## 不做的事

- 不在 Mac 跑 TTS/FFmpeg/模型/发布（publisher/ 废弃）。
- 未经 operator 消费一次性 TTL nonce，不做任何自动授权发布（人工闸口在审查后 + 发布命令显式执行）。
