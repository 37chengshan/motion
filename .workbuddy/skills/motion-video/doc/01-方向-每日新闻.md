# 01 · 方向：每日新闻（ai-news 重点 / intl / cn / ent）

> 工作目录：`code/producer`（顶层重构后路径，见 doc/08）。真相源 `src/lib/streams.ts`：`ai-news`（早晚双场）/ `intl-news` / `cn-news` / `ent-news` + `github-daily`；`world-news` deprecated 兼容值。

## ⛔ 不能破坏清单（本方向铁律，动了就丢登录态/断采集）

1. **X 专用浏览器 profile `data/x-browser/`**（Chrome 152 + X 登录态）——破坏 = 重新扫码登录 X。迁移目录时 git mv 保文件不重写，绝不重新生成 profile。
2. **CDP 端口 9223**（`X_CDP_PORT` 可覆盖）——6 个采集/验证脚本共同依赖。
3. **X 登录态 cookie** `auth_token/ct0/twid`（profile 内；明文 `data/x-cookies.json` 勿提交）。
4. **本地代理 7890**（`X_PROXY=http://127.0.0.1:7890`，X API 验证走代理）。
5. **微博 UID 缓存** `config/weibo-uid-cache.json`（误删需重解析 44 账号）。
6. **watchlist 白名单** `config/x-watchlist.json` / `weibo-watchlist.json`（103 X handle + 44 微博账号）。
7. **信源注册表** `config/news-sources.json`（trust_level 驱动打分，禁硬编码 URL；parser 五种 rss|hn-algolia|github-search|arxiv-atom|aihot-json）。
8. **AIHOT 匿名只读边界**（主源 aihot，禁索要 key/cookie）。
9. **环境变量注入不落盘**：`CONTENT_API_KEY` / `AIPING_API_KEY` / `GITHUB_TOKEN` / `TMDB_API_KEY` / `X_AUTH_TOKEN`。
10. **gitignore 保护**：`tools/*`（含 cookies）、`data/`、`runs/`、`media/`、`contracts/keys/`、`.env`、`*.db`。

## 工作流（在 code/producer 下）

```bash
# 0) 每日首件事：研究 + 打分（四方向可并行）
node scripts/daily-pipeline.ts --date <YYYY-MM-DD>        # 编排器：四方向 research→score + GitHub 候选
# 或单方向：
node scripts/daily-research.ts --date <今日> --stream ai-news --edition morning
node scripts/score-and-rank.ts --run-dir runs/<date>/<run> --stream ai-news
```

- `--date` 必填（禁止自取系统日期）；实时源失败 → `source_unavailable=true` 退出非零；回顾归档需显式 `--retrospective`；离线测试 `RESEARCH_FIXTURE=<items.json>`。
- X 补充：`node scripts/x-watch.ts --date ... --stream ai-news [--handles a,b] [--limit N]`（CDP 9223）
- 微博补充：`node scripts/weibo-watch.ts --date ... --stream cn-news [--handles rmrb,人民日报]`（m.weibo.cn 免登录）

```bash
# 1) 写稿（DeepSeek 写稿，aiping.cn OpenAI 兼容代理；`--stream` 需四流全支持——见下"缺口"）
node scripts/generate-content.ts --date ... --run-dir ... --stream ai-news
#    产物 config/content.json：每 block 必须 facts[]/URL/sourceSnapshotHash(=快照 sha256)/summary/points/stats|highlight/narration/disclaimer；URL 与 hash 不匹配退出非零；media 三轨全篇 ≤3
# 2) 素材三轨（illustration AI底图 / screenshot 截图导入 / figure|leaderboard 数据可视化）
node scripts/media-orchestrate.ts --run-dir ...          # 读 content.json blocks[].media → 生图/导入 → 回填 src
# 3) 配音 + 字幕时间轴（CosyVoice / 字级时间戳见 doc/03）
# 4) 渲染（Remotion BlockRenderer，方向排版见 doc/09 §新闻）
# 5) 审查（doc/05）→ 6) 出片 → 7) 发布（doc/06）
```

## 缺口（半迁移态，执行时收尾）

- `generate-content.ts` 的 `--stream` 目前只认 `ai-news|world-news`，**intl/cn/ent 写稿未打通**（pipeline.json 已列四方向配额 ai3/intl3/cn2/ent3）。规划执行阶段补全四流支持。

## 四流差异要点

| 流 | 侧重 | 信源特征 | 视觉要点（详见 doc/09） |
|---|---|---|---|
| ai-news | AI/大模型/产品发布 | aihot 主源 + X 官方 170 + 多 RSS | Apple 范式（单强调色）+ minimal-tech；chart/code block 高频 |
| intl-news | 国际科技 | 国际源 RSS + X 研究员 | 报纸头条 newspaper 皮肤；正式感 |
| cn-news | 国内科技 | 微博官方 375 + 国内 RSS | newspaper + 微博截图证据卡 |
| ent-news | 娱乐 | TMDB + 娱乐源 | 录屏/海报 + danmu 弹幕元素 |

## 产物结构（runs/<date>/<stream>-<edition>/）
