# 03 · 方向：实操视频 / 录屏介绍

> 口播/解说/实操教程。核心引擎 = **video-talkcraft 全流程**（`~/.workbuddy/skills/video-talkcraft/` 是权威，本文件是它在 Motion 项目的落地编排），落地工程 = `vtc/`（79 卡已复制 + 字级时间戳跑通）。

## 定位与输入

- **配音是输入，不是本方向产物**：真人录音或 TTS 皆可（CosyVoice3/edge-tts）。输入 = 一条完整配音 + 与之逐字一致的口播稿。
- 视觉语言默认 Apple 范式（`video-talkcraft/references/design-language.md`）；用户点名风格则整套 token 替换。
- 画幅：横屏 1920×1080 默认；抖音/竖屏渠道才 1080×1920。

## 流程（对应 video-talkcraft ①—⑧）

```
① 口播稿（doc/04 文案门过）→ ② 配音输入+字级时间戳(CPU) → ③ 素材 → ④ SHOTBOOK
→ ⑤ 实现（四套全局系统先行）→ ⑥ 渲染 → ⑦ 三重验收 → ⑧ 交付
```

### ② 字级时间戳（本机 CPU，skill 自带 scripts/）
```bash
# 依赖：pip install zhconv pypinyin sherpa-onnx soundfile numpy（后端 FireRedASR2-CTC int8）
python3 scripts/timestamps_cpu.py audio/full.wav script.json audio/timestamps.json   # 词级时间戳 + 口播稿逐字对齐（CJK 可靠锚点）
python3 scripts/make_timing.py audio/timestamps.json <工程>/src/timing.json          # chars 与文本 1:1
# 备选后端：--backend whisper（faster-whisper）；无 ASR 时兜底：逐句 TTS 记录起止 → build_timing 插值
```
