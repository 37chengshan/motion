# 09 · 排版模板（每方向排版卡）

> **这是"视频怎么排、长什么样"的权威文档。** 排版 = 内容骨架 × 风格皮肤，正交两层：
> - 内容骨架：信息如何落位（标题/正文/列表/代码/图表/证据卡…），基准 = producer BlockRenderer 9 类型 + video-talkcraft SHOTBOOK。
> - 风格皮肤：整套 token（色板/字阶/字体），基准 = 三套 token 系统，**禁止逐场景随手取色**。

## 三套 token 基准（引用不复制）

1. **Apple 范式**（默认，`video-talkcraft/references/design-language.md`）：
   - canvas #fff / canvas-alt #f5f5f7（深底幕 #1d1d1f）；ink #1d1d1f / ink-muted #7a7a7a；hairline #e0e0e0；**accent 唯一 #0066cc**；positive/negative 仅图表用；marker #FFE949@60%。
   - 字阶（1920×1080）：hero 128 / display 88 / headline 64 / tagline 48 / body 44 / subtitle 44 / caption 32 / micro 24；字重 400/600 为主。
   - 间距 16 基（16/24/32/48/64/96/160）；主列 ≤1440 居中；action-safe ≥96px / title-safe ≥160px；圆角 12(chip)/28(卡)/pill；投影唯一 `0 12px 60px rgba(0,0,0,.22)` 只给证据素材。
2. **手帐风**（知识科普/项目线，`project/2026-09-01-eduevidence-bilibili/engine/src/kit/index.tsx`）：
   - `C`：paper #FDFBF4 / ink #3B3A36 / red #D2544A / orange #E8843C / yellow #F5B840 / green #7BA05B / blue #5B8DB8 + noteY/G/R/B 便签底。
   - 字体 KAI（标题/手写）+ HEI（正文）+ MONO（数据）；手绘组件库：Paper/StickyNote/Stamp/HandCircle/HandUnderline/Typewriter/Highlight/ProgressCat/Kicker 等。
   - 机制动画原则：灰框预览（未 trace 节点灰显，到达点亮回弹）、彩色只上激活节点（彩色是编辑性）、主标签深墨 C.ink（防白字）、旁白逐字对齐。
3. **报纸/深色科技**（`producer/src/compositions/styles/`）：newspaper（#f5f0e1/#8b0000/Songti 正式新闻）、dark-tech（#0B1220/#22D3EE/#A78BFA，对标 Milvus 天花板，**执行阶段补实现**）。

## 新闻方向排版细节（ai-news 示例成片长什么样）

1. **片头（0-8s）**：深色/浅色幕 + hero 标题（display 88）+ 日期条（左上 micro 日期 · 右上 badge"AI 新闻"方向色）；标题下方 accent 渐变强调线。
2. **每条新闻 = 一个 block**（BlockRenderer 类型路由）：
   - 标题条：headline 64 + 方向徽章（stream 主题色 chip）；
   - 正文要点：list 卡（毛玻璃 Card + stagger 逐条出）；
   - 关键数字：number-counter（字级锚定，未到拍不显形）；
   - 数据对比：chart（横向条形图，rowH 76 / label 260 / bar 高 38，accent 色条）；
   - 代码/发布：code/terminal block（dark 底 + mono）；
   - 证据画面：真截图（aihot/X 推文存档/官网）整屏或证据卡，micro 来源行；
3. **幕底交替**：浅/深幕按段交替做分段感；同屏主体组 ≤3、每镜留空象限。
4. **字幕**：素排整句，口播逐字对齐（字级时间戳）。
5. **结尾（CTA）**：关注引导 + 明日预告 + 来源合集。

## GitHub/项目方向排版细节

1. **片头**：手帐风标题卡（KAI 大字 + 手绘下划线/印章），一句话卖点。
2. **架构/机制**：机制世界（节点-边-token），**灰框预览→trace 点亮**表达"系统如何运行"；每步与口播逐字对齐（TRACE 按词序字符权重算帧）。
3. **证据**：真实仓库页/README/文档截图（全页长截图 + 放大镜/框选，坐标机器实测）。
4. **代码**：terminal-typing / glass-code-walk 真代码（复制自仓库，非手打神似）。
5. **结尾**：GitHub 链接 + star 引导 + 三连。

## 实操录屏方向排版细节

1. 录屏主体（可 OffthreadVideo 内嵌真成片片段）；光标轨迹高亮（cursor-actor-demo）。
2. 放大镜/标注（magnifier-detail + callout-line-label），坐标来自录屏逐像素量测。
3. 人物（如有）降级角标：host-shrink-to-chip，圆心画面下 1/3，左/右下角。
4. 字幕素排 + 字级对齐（口播/录屏双时间轴）。
