# 国内新闻方向研究手册

方向定位：**国内新闻**（政策与官方发布优先）。每天单场。

> 本手册是 agent 的检索细节依据，由 SKILL.md 指向。修改需 bump version 并记录盲测。

## 一、信源表（三层）

### 官方政策三层漏斗（核心结构）

| 层级 | 说明 | 典型主体 | 权重 |
|---|---|---|---|
| **L1 中央部委** | 国家级政策、法规、规划 | 工信部、网信办、发改委、科技部、央行 | 最高 |
| **L2 地方政府** | 省市级政策落地、试点 | 省市人民政府、地方工信/科技厅 | 中 |
| **L3 行业协会** | 标准制定、行业自律、白皮书 | 中国信通院、中国电子学会、各行业协会 | 中低 |

> 检索时**自上而下**扫：L1 有重磅发布优先；L1 无则看 L2 落地；L3 用于补充与趋势判断。

## 二、检索式与过滤器

### 政策类关键词族

```
发布类：印发、发布、出台、公布、通知、意见、办法、规划
监管类：整治、规范、查处、约谈、处罚、通报、合规
产业类：试点、示范、扶持、补贴、专项、基金、签约、开工
数据类：同比增长、环比、突破、创新高、占比
```

### 收录标准

- **官方发布优先**：政府官网/部委发布 > 官方媒体（中新网/环球网）> 商业媒体
- 有明确主体（部委/地方政府/机构）+ 明确事件 + 可追溯来源
- 时效性：优先 24-48 小时内
- 有具体数字（金额、百分比、规模）的条目优先——便于视频数据卡呈现

### 排除标准

- 未经官方确认的传闻、单一匿名信源
- 纯评论/观点文章
- 娱乐八卦（归 `ent-news`）
- AI 垂类产品发布（归 `ai-news`）
- 国际时事（归 `intl-news`）

## 三、降级链

| 层 | 主方案 | 降级 1 | 降级 2 | 终点 |
|---|---|---|---|---|
| 官方政策 | 部委/政府官网 | 中新网/环球网 | IT之家/36氪 | 空 + 标注「政策源不可用」 |
| 热榜 | 60s API 微博 | 知乎/头条/百度 | DailyHotApi(6688) | 空热榜 + 标注「热榜不可用」 |
| B站舆情 | 60s API `/v2/bili` | DailyHotApi | — | 跳过 |

**硬规则**：降级链终点必须是「空 + 标注」，不得假设未部署服务存活（如 6688）。

## 四、打分权重

沿用 `score-and-rank.ts` 的 ai-pulse 模型：

```
total = heat * 0.4 + timeliness * 0.3 + sourceQuality * 0.3
```

方向特有加成：
- **官方层级加成**：L1 中央部委 > L2 地方政府 > L3 行业协会
- **数据卡加成**：含具体数字（金额/百分比/规模）的条目加分——视频化价值高
- **热榜加权**：微博热搜在榜且排名靠前 → heat 加权
- **一票否决**：无官方来源 / 无明确主体 / 纯观点无事实

去重：bigram Jaccard 相似度 > 0.8 判重。

## 六、内容安全红线（国内方向最高优先级）

- 政治敏感话题**一律照官方口径**，不做主观倾向性解读、不引申
- 涉政策内容以官方发布原文为准，不转述二手解读
- 引文 ≤40 字 + 标注 credit + 附 disclaimer
- 不收录未经官方确认的传闻、群体性事件未经通报的细节
- 涉及民族、宗教、领土等议题严格遵循官方表述
